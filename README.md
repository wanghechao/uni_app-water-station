项目拉取到本地方式
方式 1：直接下载项目压缩包，解压后通过 HBuilderX 打开（需确保已安装 HBuilderX 并配置 UniApp 环境）。
方式 2：使用 Git 命令克隆项目：git clone https://github.com/wanghechao/uni_app-water-station.git，再用 HBuilderX 打开。
